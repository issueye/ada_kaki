# AdaKaki 路线图 — 长期任务计划

> 版本：v1.0（2026-11-12）
> 定位：P0–P14 已完成（见 [DEVPLAN.md](./DEVPLAN.md)），本文件规划 **v0.2 → v1.0** 的全部后续阶段（P15–P25）。
> 执行方式：延续 DEVPLAN 的里程碑驱动模式——每阶段有目标/任务清单/验收标准，完成后勾选并提交；架构级变更须回写 [DESIGN.md](./DESIGN.md)。
> 关联文档：[设计文档](./DESIGN.md) · [UI 评审](./UI-REVIEW.md) · [README](../README.md)

---

## 0. 愿景与目标

**AdaKaki v1.0：一款可信的、跨平台的 AI 驱动终端控制台。**

三根支柱，对应三个里程碑主题：

| 支柱 | 含义 | 对应里程碑 |
|---|---|---|
| **可信** | 人对 AI 操作有完全的可见性与控制权（蒙版/护栏/审计已就绪，继续深化协同） | v0.2 协同深化 |
| **可用** | 超出 Windows 单平台、超出开发者手动安装的范围（跨平台/打包/自动更新） | v0.3 跨平台与分发 |
| **耐用** | 会话数量与输出吞吐上规模后仍然流畅；日常操作更快 | v0.4 效率与规模 |

**发布定义（v1.0 DoD）**：Windows/macOS/Linux 三平台安装包 + 签名与自动更新 + 全量测试绿 + 手动验收清单通过 + 用户文档完整。

## 1. 执行规则（每一阶段通用）

1. 开工前：读本文件对应阶段 + DESIGN.md 相关章节；如设计缺失，先补设计再动代码。
2. 任务顺序即依赖顺序；带 ⚠ 的项有跨阶段影响，完成时必须回写 DESIGN.md。
3. 质量门（缺一不勾）：`go build ./... && go vet ./... && go test ./...` 全绿 → GUI 冒烟存活 → 该阶段手动验收清单通过 → 提交（信息引用阶段号）。
4. 每阶段收尾：更新本文件勾选状态 + README 功能清单 + DESIGN.md（如涉架构）。
5. 预估工作量按"AI 结对开发 + 人工验收"计（与 P0–P14 实际节奏一致），仅供参考排期。

## 2. 里程碑一：v0.2 — 可信与协同深化

> 主题：让"人机协同"成为完整闭环——AI 能看见的更多（资源/通知），人能掌控的更多（规则 UI/审计检索/代理）。

### P15 MCP 资源与通知（0.5 天）

目标：MCP 客户端能以资源方式浏览会话，工具变化可被发现。

- [ ] `resources/list`：每个会话一个资源（`session://<id>`，含 kind/title/state 元数据），`resources/read` 返回该会话 `screen_session` 文本
- [ ] capabilities 增加 `resources`；会话创建/关闭时发送 `notifications/resources/list_changed`
- [ ] `tools/listChanged` 通知（当前 tools 固定，为未来工具集变化预留）
- [ ] 测试：资源列表/读取/通知的端到端（复用 mcp_test 装置）
- [ ] 手动：ZCode/Claude 中会话出现在资源面板，读取内容正确

验收：客户端（ZCode）资源面板可见会话并可读取屏幕文本。

### P16 MCP stdio 代理模式（1 天）⚠

目标：`adakaki mcp` 不再独立建会话，而是**代理到正在运行的 GUI**——AI 操作的会话与人在 GUI 看到的会话是同一批（蒙版/护栏/审计全部生效于 GUI 会话）。

- [ ] GUI 控制面增加完整 MCP 代理端点（已有 /mcp，stdio 进程改为其客户端）
- [ ] `adakaki mcp` 启动时探测 GUI（握手控制面 + token 文件）；GUI 未运行 → 提示并回退当前独立引擎模式
- [ ] 连接断开重连；请求串行化（stdio 单客户端，无并发问题）
- [ ] 安全：代理复用 GUI 侧护栏与蒙版，无旁路
- [ ] 测试：GUI（httptest 控制面）+ stdio 代理进程的端到端
- [ ] 文档：README 配置示例更新（推荐"GUI + 代理"模式）

验收：AI 经 stdio 创建的会话出现在 GUI 侧栏，蒙版与审计同步生效。
依赖：无（控制面已存在）。风险：控制面协议需覆盖全部 12 工具（现为复用，改动小）。

### P17 护栏规则编辑器 + 审计检索（1 天）

目标：规则与审计从"文件配置 + 平铺列表"升级为可管理的 UI。

- [ ] 设置·安全页：护栏规则列表（内置只读 + 自定义增删），添加时正则校验（复用 `AddCustom` 错误返回）
- [ ] 自定义规则持久化到 config（已有 `guard_deny/confirm` 字段，双向绑定）
- [ ] 审计窗口：按工具/客户端/结果（ok/error/denied）过滤 + 关键字搜索 + 时间范围（今日/近7日/全部）
- [ ] 审计导出：当前过滤结果导出 CSV / JSONL 到用户选择路径
- [ ] 测试：过滤谓词与导出格式的单测

验收：不碰 config.json 即可增删护栏规则；200 条审计中 10 秒内定位一条记录。

## 3. 里程碑二：v0.3 — 跨平台与分发

> 主题：从"Windows 上的开发项目"到"三平台可安装的软件"。

### P18 macOS / Linux 适配（2 天）⚠

目标：`CGO_ENABLED=0` 交叉编译三平台可运行，核心路径全绿。

- [ ] `internal/shells` 平台化：darwin（zsh/fish/iterm2 检测）、linux（bash/zsh/fish + $SHELL）、保留 Windows 现状
- [ ] 凭据存储抽象 `store.Secret`：Windows DPAPI（现有）/ macOS Keychain（`security` 命令行，无 cgo）/ Linux libsecret（`secret-tool` 可选，缺失时降级提示）
- [ ] OpenSSH agent：`SSH_AUTH_SOCK` 已就绪（agent_other.go），验证 macOS launchd socket
- [ ] 主题/字体：三平台默认等宽字体探测（SF Mono / JetBrains Mono / DejaVu Sans Mono）
- [ ] CI：GitHub Actions 三平台矩阵（build + test；GUI 测试仅 macOS runner 按框架现状）
- [ ] 手动：macOS / Linux 真机冒烟清单（终端/SSH/MCP stdio）

验收：三平台 `go build && go test` 绿 + 至少 macOS 真机跑通核心清单。
风险：ui 包 Linux 后端依赖 GTK（需系统库）——文档明示运行时依赖，CI 只验证编译与纯逻辑测试。

### P19 打包与安装（1 天）⚠

目标：一条命令产出可分发安装包。

- [ ] `mygo build` 接入：应用图标、名称/版本/厂商元数据、ghostty-vt 动态库 vendor 到资源目录（免首跑下载）
- [ ] Windows：MSI/NSIS 安装包 + 可选代码签名（`signtool`，证书留给发布者）
- [ ] macOS：.app + .dmg（框架打包器），ad-hoc 签名
- [ ] Linux：.deb + AppImage
- [ ] 发布脚本：版本号注入（`-ldflags -X`）、CHANGELOG 生成、GitHub Release 上传
- [ ] 验收：三平台安装包在本机安装后完整走一次核心清单

### P20 自动更新（0.5 天）⚠

- [ ] 接入 mygo updater 插件（Sparkle 式：签名清单 + 增量更新 + 更新窗口）
- [ ] 更新清单托管：GitHub Releases + 固定 base URL（CLI 已校验 query/fragment）
- [ ] 设置页：更新通道（stable/beta）+ 手动检查按钮
- [ ] 验收：从 v(n) 自动升到 v(n+1)，签名校验拒绝篡改包

## 4. 里程碑三：v0.4 — 效率与规模

### P21 性能与规模（1 天）

目标：50 会话 + 高吞吐输出不卡 UI，资源占用有预算。

- [ ] 基线测量：50 会话 / 单会话 10MB 输出的内存与 CPU（`internal/idlemem` 思路）
- [ ] 会话视图 LRU：>12 个标签时卸载非激活 xterm…（原生 UI 下改为：非激活分格保留 Terminal 但停止 Mirror 泵；滚回超限降级）
- [ ] run_command 轮询优化：事件驱动（等 Exited/静默）替代固定 60ms 轮询
- [ ] 预算入 CI：Hello 级应用体积与空闲内存回归阈值
- [ ] 验收：50 会话场景下 UI 帧稳定（inspector 帧耗时 < 4ms），冒烟通过

### P22 效率工具集（1 天）

- [ ] 命令片段库：保存/命名/搜索常用命令，Find Bar 旁入口，插入当前会话（或直接 run_command）
- [ ] SSH 档案分组与快速连接面板（Ctrl+Shift+S）
- [ ] 全局快捷键唤起/隐藏主窗口（框架 global shortcuts）
- [ ] 会话收藏/置顶（侧栏右键）
- [ ] 验收：手动清单——从唤起窗口到命令执行 ≤ 3 次按键

### P23 国际化（0.5 天）

- [ ] 框架 i18n 机制接入（locales 包），抽取全部 UI 字符串
- [ ] 中文（默认）+ 英文，语言跟随系统 + 设置页覆盖
- [ ] MCP 工具描述双语（AI 客户端多为英文语境）
