# UI 评审报告

> 评审范围：主窗口（侧栏/标签栏/终端区/Find Bar）、弹出窗口、全部对话框（退出/护栏/主机指纹/SSH/设置/自定义命令）、审计查看窗口
> 评审维度：现代化 / UI 设计合理性 / 交互设计 / 界面排版 / 图标体系 / 文案
> 结论：**结构合理，图标体系为最大硬伤；另发现 1 处与现状矛盾的过期文案**。以下按维度列出问题（E 编号）与整改状态。

## 1. 图标体系（最严重）

| # | 问题 | 整改 |
|---|---|---|
| E1 | **12 处 emoji 充当图标**（🛡⚙＋✕🤖⚠✓✗☑●◐↑↓）。Windows 上走 Segoe UI Emoji：彩色、字重不齐、DPI 缩放发虚、与系统原生 UI 的单色图标范式直接冲突 | 全部替换为内嵌 **Lucide 风格单色 SVG**（`ui.Icon` 渲染，颜色/字号继承文字，任意 DPI 矢量清晰） |
| E2 | 侧栏会话项无图标（`SidebarItem` 传 nil）——侧栏只剩文字，缺视觉锚点，本地/SSH 两节靠标题区分 | 本地会话 → terminal 图标；SSH 会话 → globe 图标 |
| E3 | 会话状态点用文本"●"/"◐"，与 emoji 混排基线不齐 | 状态点改为 SVG 圆点（fill 继承文字色），状态色语义集中（运行/退出/启动/被 Agent 操作） |

## 2. UI 设计合理性

| # | 问题 | 整改 |
|---|---|---|
| E4 | **过期矛盾文案**：SSH 对话框仍显示"注意：v1 不校验主机指纹（见设计文档）"——P10 已实现 TOFU 指纹校验，文案与事实相反 | 删除，改为一行现行说明（首次连接将请求确认指纹） |
| E5 | 设置对话框 7 组设置平铺一列，无分组层次 | 按功能分组加小节标题：外观 / 会话 / MCP / 安全 / SSH |
| E6 | 图标按钮无 Tooltip、无无障碍命名（文档要求 icon-only 按钮必须 `Label`） | 所有 icon-only 按钮补 `Label` + `Tooltip` |
| E7 | 退出/护栏弹窗用"⚠ …！"感叹号堆叠，警示感靠符号而非层级 | 三角警示 SVG 图标 + Danger 色文字，措辞平实 |

## 整改验证

- `go build ./... && go vet ./... && go test ./...` 全绿
- 全部图标为仓库内 SVG 常量（Lucide ISC 许可），无外部资源、无运行时下载

## 增补（右键功能核对时发现）

| # | 问题 | 整改 |
|---|---|---|
| E19 | **分屏可达性缺口**：分格被终端视图铺满时，右键命中的是终端插件自带菜单（复制/粘贴/全选/清回滚），分格菜单（分屏/关闭）只在空分格等非终端区域可达 | ① 终端 `RightClick` 改为 `RightClickCopyOrPaste`（Windows Terminal 惯例：右键=复制选区/无选区则粘贴）；② 标签/侧栏会话菜单新增「向右分屏/向下分屏」，自动聚焦该会话所在分格再拆分——分屏从任何右键位置都可达 |
| E20 | 右键非焦点分格时，分屏/关闭作用于**先前焦点分格**而非右键所指向的分格 | 分格菜单打开即聚焦该分格（右键即聚焦，上下文菜单作用于所指对象） |

| # | 问题 | 整改 |
|---|---|---|
| E21 | 设置以 460px 弹窗承载，七组设置拥挤，且无法承载 300+ 配色目录的选择 | **独立设置窗口，左右布局**：左侧分类导航（外观/终端/会话/MCP/安全，`ui.Sidebar` + 可拖 `ui.Split`），右侧滚动内容区——现代 WebUI 设置页范式 |
