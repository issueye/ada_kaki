# UI 评审报告

> 评审范围：主窗口（侧栏/标签栏/终端区/Find Bar）、弹出窗口、全部对话框（退出/护栏/主机指纹/SSH/设置/自定义命令）、审计查看窗口
> 评审维度：现代化 / UI 设计合理性 / 交互设计 / 界面排版 / 图标体系 / 文案
> 结论：**结构合理，图标体系为最大硬伤；另发现 1 处与现状矛盾的过期文案**。以下按维度列出问题（E 编号）与整改状态。

## 1. 图标体系（最严重）

| # | 问题 | 整改 |
|---|---|---|
| E1 | **12 处 emoji 充当图标**（🛡⚙＋✕🤖⚠✓✗☑●◐↑↓）。Windows 上走 Segoe UI Emoji：彩色、字重不齐、DPI 缩放发虚、与系统原生 UI 的单色图标范式直接冲突 | 全部替换为内嵌 **Lucide 风格单色 SVG**（`ui.Icon` 渲染，颜色/字号继承文字，任意 DPI 矢量清晰） |
| E2 | 侧栏会话项无图标（`SidebarItem` 传 nil）——侧栏只剩文字，缺视觉锚点，本地/SSH 两节靠标题区分 | 本地会话 → terminal 图标；SSH 会话 → globe 图标 |
| E3 | 会话状态点用文本"●"/"◐"，与 emoji 混排基线不齐 | 状态点改为 SVG 圆点（fill 继承文字色），状态色语义集中（运行/退出/启动/被 Agent 操作） |
